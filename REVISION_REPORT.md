# Assignment 3 — Final Report Guide

**Deadline:** 11:59 p.m., December 3, 2026 (Pacific Time).

Follow the official Assignment 3 instructions on Canvas. This file is a guide, not a report to submit. Create your own Word document named `FinalReport.docx` and upload it to your repository root and Canvas.

## Getting started

1. Join a group in the Assignment 3 group set on Canvas, even if working individually (one member for individual work, two for pairs).
2. From the [starter repository](https://github.com/ruishanwu/CMPT376W-Assignment3), select **Use this template** → **Create a new repository**. Make your copy public. Pairs share one repository; both partners must contribute to its commit history.
3. Review and revise `README.md` and `docs/INSTALL.md` only. Use `docs/FACT_SHEET.md` as the reference for technical facts and intended readers. Leave the fact sheet, program, and sample data unchanged.
4. Preview and commit both revised Markdown files to the `main` branch. Markdown and technical writing are assessed; GitHub proficiency is not.
